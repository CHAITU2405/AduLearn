# Brand assets

Place the supplied **AduLearn logo** here as one of:

- `adulearn-logo.png`
- `adulearn-logo.svg`
- `adulearn-logo.webp`

The app picks it up automatically at build time (see `src/components/brand/Logo.tsx`).
Until the file is present, a simple text wordmark placeholder is shown instead.
The placeholder is **not** a redesign of the logo — replace it by adding the real file.
